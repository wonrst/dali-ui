## 보관 기준

연구 보고서는 당시의 실험·판단 기록이며 최종 제품 결정은 최종 요약을 기준으로 읽으세요. 수치와 실험 내용은 바꾸지 않았고, 링크와 줄 끝 공백만 정리했습니다. 보관된 MD·미디어의 상대 링크는 유지하며 로컬 절대 링크는 보관 경로로 고쳤습니다.

영상 29개는 저장소 용량을 위해 제외했습니다. 10 MiB 초과 영상과 사용자가 제외한 Vogel12 2개·A-R 1개가 대상입니다. 원본 영상은 변경·변환·삭제하지 않았습니다. 실행 파일, RPM, 빌드 디렉터리, 원시 로그, 진단 코드도 이 문서 모음에 포함하지 않습니다. 미보관 파일 링크는 깨진 링크 대신 `로컬 자료` 경로로 표시합니다. 원래 보고서의 명령/경로는 당시 환경을 설명하는 기록이며 이 폴더만으로 실험을 재실행할 수 있다는 뜻은 아닙니다.

이미지와 영상은 재측정·재압축하지 않은 기존 자료입니다. 온라인 자료는 링크를 눌렀을 때만 열며 HTML을 여는 것만으로 다운로드하지 않습니다.
